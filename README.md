 # FULL STACK PROJECT

> מוצאים את המנויים ששכחת מהם, לפני שהם מחייבים אותך שוב.

## הבעיה

כמעט לכל אחד יש מנויים שהוא כבר לא משתמש בהם: אפליקציות, שירותי סטרימינג,
ניסיון חינם שהפך לחיוב חודשי. כל אחד מהם קטן, אבל ביחד הם מצטברים לסכום
שיורד מהאשראי כל חודש, בלי שאף אחד שם לב.

הבעיה היא לא שאנשים לא רוצים לבטל. הבעיה היא שהם לא יודעים מה יש להם,
מתי החיוב הבא, ואיך בכלל מבטלים.

## הפתרון

מערכת שסורקת את קבלות המנויים בתיבת ה-Gmail, מזהה את כל המנויים
החוזרים, מראה מתי כל אחד מהם יחייב בפעם הבאה, ושולחת אותך ישירות
לדף הביטול.

## מסלול המשתמש

1. **הרשמה:** המשתמש נרשם עם חשבון Google כדי לאמת את זהותו.
2. **חיבור תיבת מייל:** המשתמש בוחר איזו תיבת Gmail לסרוק:
   זו שאיתה נרשם, או חשבון אחר.
3. **סריקה:** הסריקה רצה ברקע. המשתמש לא צריך לחכות מול המסך,
   והוא מקבל הודעה כשהיא מסתיימת.
4. **תוצאות:** רשימת כל המנויים, ולכל אחד: מה זה, כמה הוא עולה,
   ומתי החיוב הבא.
5. **ביטול:** כפתור ליד כל מנוי שמוביל ישירות לדף הביטול.
   בסריקה הבאה המערכת בודקת שהחיוב באמת הפסיק.

## אבטחה ופרטיות

המערכת ניגשת למידע רגיש, ולכן אלה עקרונות שלא מתפשרים עליהם:

- **הרשאה מינימלית:** גישת קריאה בלבד למייל. אי אפשר לשלוח, למחוק או לשנות.
- **סריקה ממוקדת:** רק מיילים שנראים כמו קבלות, לא כל התיבה.
- **לא שומרים מיילים:** שומרים רק שם שירות, סכום ותאריך.
  תוכן המיילים לא נשמר אף פעם.
- **המשתמש בשליטה:** אפשר לנתק את המייל ולמחוק את כל המידע בכל רגע.

## מה נכנס לגרסה הראשונה (MVP)

- [ ] הרשמה והתחברות עם Google
- [ ] חיבור תיבת Gmail
- [ ] סריקה ברקע וזיהוי מנויים
- [ ] חישוב תאריך החיוב הבא
- [ ] מסך תוצאות עם קישורי ביטול

**לא בגרסה הראשונה:** ביטול אוטומטי על ידי סוכן AI, וחיבור ישיר לבנק.

## טכנולוגיות

| Git | ניהול קוד בצוות, branches ו-Pull Requests |
| Linux ו-Bash | סקריפטים לאוטומציה, גיבויים ותזכורות |
| Docker | כל רכיב רץ בקונטיינר משלו: אתר, worker, בסיס נתונים |
| בסיסי נתונים | שמירת משתמשים ומנויים
